# Introducing Web Console (Beta): Code Where You Build on Salesforce

> A modern browser IDE embedded in Salesforce for fast investigate-fix-validate loops, replacing the legacy Developer Console.

**Source:** [Introducing Web Console (Beta)](https://developer.salesforce.com/blogs/2026/04/introducing-web-console-beta-code-where-you-build-on-salesforce) | **Published:** 2026-04-09 | **Tags:** salesforce, devops

## Summary
Beta opening April 14, 2026, Web Console is a browser-based IDE embedded directly into Salesforce surfaces (Setup, Apex Jobs, etc.) so developers don't leave the platform to debug. It targets reactive investigation: debug log viewing, SOQL execution, Query Plan Inspector, Anonymous Apex, and quick in-context Apex edits with org-aware navigation. The pitch is "code where you build" — a shorter path from "something broke" to "found it, fixed it, validated it" than bouncing between disconnected tools.

## Key Takeaways
- Positioned as the modern successor to the legacy Developer Console.
- Beta workflows: debug logs, SOQL + Query Plan, Anonymous Apex, in-context quick edits, metadata navigation.
- Guardrails: Apex editing is read-only in production; inline edits allowed in sandboxes/non-prod.
- Off by default — admin opt-in via Web Console Setup page; available across orgs/editions during beta.

## Why It Matters
A faster debugging surface for any Salesforce engagement. Useful to flag to client dev teams (Cretelligent, MAI, Cetera) standardizing tooling.
