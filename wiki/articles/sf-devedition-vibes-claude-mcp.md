# New in Salesforce Developer Edition: Agentforce Vibes IDE, Claude 4.5, MCP

> Free Salesforce Dev Edition now ships a full AI dev loop: a browser VS Code IDE, Claude Sonnet 4.5 vibe coding, and Hosted MCP servers.

**Source:** [New in Salesforce Developer Edition](https://developer.salesforce.com/blogs/2026/04/new-developer-edition-agentforce-vibes-claude-mcp) | **Published:** 2026-04-15 | **Tags:** salesforce, ai

## Summary
Announced at TDX April 2026, every free Developer Edition org now includes three additions that turn it into a full AI development environment. Agentforce Vibes IDE is a browser-based, org-aware VS Code (formerly Code Builder) that launches from Setup with CLI, extensions, and GitHub preconfigured. Agentforce Vibes is the enterprise vibe-coding agent with Claude Sonnet 4.5 as default — it reads your real org metadata first (no hallucinated fields) and runs Plan/Act modes. Hosted MCP Servers let any MCP client (Claude Desktop, Cursor, Claude Code) query the org over OAuth 2.0, respecting the org security model.

## Key Takeaways
- Three free features: Vibes IDE (environment), Vibes + Claude 4.5 (AI partner), Hosted MCP (external AI data access).
- Dev Edition limits: 110 requests/month, 1.5M tokens/month, monthly refresh through 2026-05-31, then a one-time final allocation.
- Hosted MCP (Salesforce infra, OAuth, sObject/actions/flows) vs DX MCP (local machine, CLI creds, 60+ dev tools).
- Stretch tips: use Plan before Act, write specific prompts, retrieve only task-relevant metadata.

## Why It Matters
Directly relevant to Mac's Salesforce + AI/MCP consulting. Free environment to prototype Agentforce and MCP integrations for client work (Harvey, Litify, NBCU, Blink) without burning production quota.
